# Indian Travel Planner

Indian Travel Planner is a dynamic, responsive website designed to help users plan their travel itineraries across various cities in India. With a user-friendly interface and interactive design, users can input their desired city and the number of days for their visit, and the website will generate a personalized itinerary complete with recommended sightseeing spots and hotel options.

## Overview

Planning your travel adventure in India just got easier! Indian Travel Planner offers a simple yet effective way to explore the must-see attractions in major Indian cities. Just enter the name of the city and the number of days you plan to stay, and the website generates a detailed itinerary for you, featuring daily activities and recommended hotels.

## Features

- **User-Friendly Interface:** A clean and responsive design for seamless travel planning.
- **Interactive Itinerary Generation:** Input your travel preferences and receive a day-by-day plan.
- **City-Specific Itineraries:** Supports multiple cities such as Mumbai, Delhi, Bengaluru, Kolkata, Chennai, Hyderabad, Ahmedabad, Pune, Jaipur, Surat, Lucknow, Kanpur, Nagpur, Visakhapatnam, Chandigarh, and Coimbatore.
- **Attractive Visuals:** Uses Google Fonts and high-quality background images sourced from Unsplash.
- **Responsive Design:** Optimized for desktops, tablets, and mobile devices.

## Technologies Used

- **HTML5:** For structuring the web page.
- **CSS3:** For styling and responsive design.
- **JavaScript:** For dynamic content and interactive itinerary generation.
- **Google Fonts:** For enhanced typography.
